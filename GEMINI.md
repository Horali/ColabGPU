# ColabGPU — Agent Rules & Guidelines

Repository: `Horali/ColabGPU` (private, `main` branch)

## Commit & Working Rules
1. **Push to `main`**: Push small commits regularly to maintain daily GitHub contribution activity.
2. **Never commit secrets/binaries**: Keep `cloudflared.exe`, `colab_key*`, `.host`, and credentials ignored.
3. **No AI attribution**: No "Co-Authored-By" or AI credit trailers. Commits belong exclusively to the user (`Horali`).
4. **Stage specific files by name**: Avoid `git add .` or `git add -A`.
5. **Commit style**: Conventional lowercase prefix (`feat:`, `fix:`, `docs:`, `chore:`).
